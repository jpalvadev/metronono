1. Deepen Lookahead Scheduler & Audio Voice Lifecycle

src/audio/ToneTransportScheduler.ts • src/audio/DrumKitPlayer.ts • src/domain/dawson/DawsonEngine.ts • src/audio/AudioMixer.ts
Problem

Audio stuttering occurs because uncollected Web Audio nodes leak on every sample stroke, monophonic synths choke on rapid subdivisions, and synchronous domain calculations execute inside the real-time audio clock tick.

Solution

Deepen the Lookahead Scheduler module to pre-resolve measure stroke windows ahead of time and manage pooled audio voices with automatic lifecycle disconnection at the hardware seam.

2. Deepen Drum Staff Metric Alignment & Margin Geometry

src/notation/DrumStaffFormulaRenderer.ts • src/components/dawson/DrumStaffViewer.tsx • src/notation/DrumVoicePAS.ts
Problem

Drum staff margins clip high cymbal stems and tuplet brackets, while linear coordinate mapping produces severe visual misalignment with VexFlow's actual note positions in triplets.

Solution

Deepen DrumStaffFormulaRenderer to compute dynamic vertical headroom, enforce metric spacing, and expose exact note-anchored X coordinate interpolation at the layout seam.

3. Replace Rigid Discrete Slots with a Continuous Metric Timeline Seam

src/components/dawson/PartitureFormulaCanvas.tsx • src/components/dawson/PartitureFormulaEditor.tsx • src/domain/dawson/SubdivisionFormula.ts
Problem

PartitureFormulaCanvas relies on a shallow discrete slot array (strokesToSlots) that breaks whenever triplets (1/3 beat) and straight figures (1/4 beat) coexist in the same measure.

Solution

Deepen the formula canvas module to operate directly on continuous metric time offsets (timeInMeasure) rather than coercing measures into a homogeneous slot array.

  • ✓ delete strokesToSlots conversion churn
  • ✓ editor coordinates match sounding audio events
